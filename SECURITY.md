# Security Policy

## Supported versions

Security fixes are considered for maintained MaddPrestige 2.x releases and
release candidates. Older versions are not actively maintained.

## Reporting a vulnerability

Please do not report security vulnerabilities through a public GitHub issue.
Use [GitHub's private vulnerability reporting](https://github.com/zhang-lixue/MaddPrestige/security/advisories/new)
for this repository instead.

Include the affected version, the potential impact, and enough steps or
examples to reproduce and understand the issue. Remove unrelated secrets,
player data, and private server details from anything you submit.
