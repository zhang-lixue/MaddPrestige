# Numeric Prestige example

This generic content example uses one Paper play-time requirement, no cost, no reward, no stage ladder, and no
external rank provider. It becomes active only after an administrator publishes it as an immutable revision. Its
one-minute value exists only to demonstrate editable configuration syntax; it is not a production recommendation.

The five files are required by the revision format, but omitted settings inherit documented safe defaults. Empty
maps, disabled integrations, `ALL`, `GREATER_OR_EQUAL`, `LIVE`, unlimited maximum, zero cooldown, and the canonical
reset policy therefore do not need to be repeated.

Review and change every gameplay value before activation. The canonical guided path is documented in
[`docs/QUICK_START.md`](../../docs/QUICK_START.md).
